Medi-Scan dev sign-in

Produces a real Google ID token so the backend's auth endpoints can be exercised with curl before the sign-in UI exists. It talks to Google and to nothing else — there is no call to the Medi-Scan API anywhere on this page.

Local development only. This page is never deployed and is not part of the client app. An ID token is a credential: paste it into your terminal, not into a chat, an issue, or a commit.

Enter a client id, then press Load.

The client id is typed in rather than committed, so this file holds no configuration for any real project. Add http://localhost:5500 as an authorised JavaScript origin on the OAuth client first, and remove it when you are done. See README.md next to this file.
