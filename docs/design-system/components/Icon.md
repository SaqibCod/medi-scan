Inline stroke icons on a 24-unit grid, 1.6 stroke, round caps, `currentColor`.

- **Provide** `name`; `size` defaults to 18. Colour comes from the parent's `color`.
- These are the only icons the system uses. No emoji, no filled glyphs, no brand logos.
- Icons are decorative (`aria-hidden`); an icon-only control gets its name from IconButton's `label`.
