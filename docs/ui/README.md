# UI designs

Screenshots of the approved Medi-Scan mockups, one PNG per artboard. They are the visual reference for the frontend phases. The design rules (tokens, type, components, voice) are in `docs/design-system/`.

**How to use them**

- Match layout, spacing, type, copy and states. Build with the tokens and components in `docs/design-system/`, never by sampling colours from these images.
- Copy in the screenshots is the intended wording. Numbers, names and dates in them are made-up examples.
- Desktop artboards are 1440 px wide, phone artboards 390 px.
- If a screenshot and `docs/api-contract.md` disagree (a field, a code, a limit), the contract wins. Note the difference in the phase report.
